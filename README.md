## Описание

Модель находит объекты на кадре, ведёт их между кадрами и выдаёт итоговое число. Работает как с отдельными снимками, так и с записанным видео.

## Подготовка

Сначала скопируйте себе копию проекта с хостинга и перейдите в полученный каталог.

Дальше соберите изолированное окружение — команды немного различаются по системам.

<details>
<summary>Ветка macOS / Linux</summary>

Создание и включение окружения одной строкой:

```
python3 -m venv venv && source venv/bin/activate
```
</details>
<details>
<summary>Ветка Windows</summary>

Там же, но через запускаемый файл активации:

```
py -m venv venv && venv\Scripts\activate.bat
```
</details>

Пакеты ставятся из списка зависимостей проекта:

```
python -m pip install -r requirements.txt
```

Точка входа — один скрипт:

```
python main.py
```

Пути и порог уверенности задаются аргументами командной строки, полный список печатается по `-h`.
